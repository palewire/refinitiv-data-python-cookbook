# Installing the library

The [LSEG Data Library for Python](https://pypi.org/project/lseg-data/) is distributed as a Python package named `lseg-data`. To install it, you must have a Python package manager, such as [uv](https://docs.astral.sh/uv/), installed on your machine.

## Installing with pip

If you have pip installed, you can install the library by running the following command in your terminal:

```zsh
pip install lseg-data
```

## Installing with uv

If you prefer to use [uv](https://docs.astral.sh/uv/), you can install the library by running the following command in your terminal:

```zsh
uv add lseg-data
```
